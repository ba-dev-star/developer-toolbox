How to use the Hash Generator

  1. Type or paste your text into the Your text box. The hashes appear as you type.
  2. Press Copy next to the hash you need: MD5, SHA-1, SHA-256, SHA-384 or SHA-512.
  3. Tick Capital letters if you want the hash in uppercase.
  4. To check a hash you received, paste it in Compare with a hash. The tool tells you if it matches your text and which algorithm it belongs to.

About this tool

A hash is a short fixed-length fingerprint of some data. The same text always gives the same hash, and even a tiny change gives a completely different one. Developers use hashes to check that data was not changed, to compare files and texts, and to create identifiers. This tool calculates hashes of text in your browser, so your text is never uploaded.

Frequently asked questions

Which hash algorithm should I use?

Use SHA-256 or stronger when security matters. MD5 and SHA-1 are broken for security because different inputs with the same hash can be created, so use them only for simple checksums.

Can a hash be reversed or decrypted?

No. A hash is a one-way function, so you cannot recover the original text from it. Attackers only try to guess the text and compare the hashes.

Can I use it to store passwords?

No. Plain hashes like SHA-256 are too fast and are not suitable for passwords. Use a password hashing function such as bcrypt, scrypt or Argon2 with a salt, on your server.

Why does my hash change when I add a space or a new line?

Every character counts, including spaces and line breaks. Even one extra invisible character gives a different hash.

How long is each hash?

MD5 has 32 characters, SHA-1 has 40, SHA-256 has 64, SHA-384 has 96 and SHA-512 has 128. The compare box uses these lengths to tell you which algorithm a hash probably belongs to.

Can it hash files?

Not yet. This tool hashes text only. Also, the SHA hashes need a secure page, so they work on the live website (https).
