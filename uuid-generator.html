UUID Generator

Generate random UUID v4 identifiers. Choose how many you need, then copy them.

How to use the UUID Generator

  1. Choose how many UUIDs you need, from 1 to 100.
  2. Tick Uppercase or Remove hyphens if you need a different format.
  3. Press Generate to create them. Each UUID is on its own line.
  4. Press Copy to copy the whole list.

About this tool

A UUID (Universally Unique Identifier) is a 128-bit ID that is practically unique, so you can create IDs for database rows, files or requests without coordinating with anyone. This tool creates version 4 UUIDs, which are random.

Frequently asked questions

What is a version 4 UUID?

It is a UUID built from random numbers. The tool uses the secure random generator of your browser.

Can two UUIDs be the same?

In practice, no. The chance of a repeat is so small that it can be ignored for normal use.

Is a UUID the same as a GUID?

Yes. GUID is the name Microsoft uses for the same kind of identifier.

Can I use a UUID as a password or secret?

UUIDs are meant to identify things, not to protect them. For passwords, use the Password Generator.

Are my UUIDs stored anywhere?

No. They are created in your browser and disappear when you close the page.
