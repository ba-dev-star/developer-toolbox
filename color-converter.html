Color Converter

Convert colors between HEX and RGB. Type in either one, or pick a color.

How to use the Color Converter

  1. Type a HEX color like #4F46E5 in the HEX box, or type the red, green and blue numbers.
  2. The other boxes and the preview update right away.
  3. You can also click the color square to pick a color visually.
  4. Press Copy HEX or Copy RGB to copy the value for your CSS.

About this tool

HEX and RGB are two ways to write the same color. HEX is common in CSS and design tools, and RGB gives the amount of red, green and blue from 0 to 255. This tool converts between them instantly.

Frequently asked questions

Can I type the short form like #4AF?

Yes. A 3-digit HEX color is expanded automatically, so #4AF becomes #44AAFF.

Do I need to type the # sign?

No. The converter understands HEX with or without the # sign.

Does it support transparency (alpha)?

Not yet. The converter works with solid colors, and RGB values go from 0 to 255.

What does the copied RGB look like?

It is ready for CSS, for example rgb(79, 70, 229).
