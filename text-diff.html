Text Diff Checker

Paste two versions of a text or code and see exactly which lines were added or removed. Nothing leaves your browser.

Differences

How to use the Text Diff Checker

  1. Paste the first version of your text or code into the Original box.
  2. Paste the second version into the Changed box.
  3. Press Compare. Removed lines are shown in red with a minus sign, and added lines are shown in green with a plus sign.
  4. Use the options to Ignore case, Ignore whitespace, or Show only changes. The result updates when you change an option.
  5. Press Swap to exchange the two texts, or Load example to see a sample.

About this tool

A diff shows what changed between two versions of a text. Developers use it to review code changes, compare configuration files, and check what was edited in a document. This tool compares the two texts in your browser, so nothing is uploaded.

Frequently asked questions

How does the comparison work?

The tool compares the texts line by line. It finds the largest set of lines that both texts share, in the same order, and shows every other line as removed or added.

Why does a changed line appear twice?

A line that was edited is shown as the old line in red and the new line in green. The tool compares whole lines and does not highlight the changed words inside a line.

What do the options do?

Ignore case treats Hello and hello as the same. Ignore whitespace ignores spaces at the start and end of a line and extra spaces between words. Show only changes hides the unchanged lines and keeps two lines of context around each change.

Do different line endings count as changes?

No. Windows and Mac or Linux line endings are treated the same, and a final empty line is ignored.

Is there a size limit?

Texts that are mostly similar can be very large. Texts that are completely different are limited to about 2000 lines each, and the tool shows a message when a comparison is too large.
