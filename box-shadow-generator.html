How to use the CSS Box Shadow Generator

  1. Start with a ready-made shadow, like Soft or Large, or build your own with the sliders.
  2. Move the sliders for the horizontal offset, vertical offset, blur, spread and opacity, and pick the shadow color.
  3. Tick Inset to draw the shadow inside the box.
  4. Press Add layer to stack more shadows, and click a layer button to edit it.
  5. Press Copy CSS and paste the line into your style sheet.

About this tool

The CSS box-shadow property adds a shadow around a box, such as a card, a button or an image. Shadows make elements look raised from the page and help users see what is clickable. This tool builds the code with a live preview, in your browser.

Frequently asked questions

What do the values mean?

The horizontal offset moves the shadow right (positive) or left (negative). The vertical offset moves it down (positive) or up (negative). Blur makes the edge soft, and 0 gives a sharp edge. Spread makes the shadow bigger (positive) or smaller (negative) before the blur.

What does Inset do?

An inset shadow is drawn inside the box instead of outside. It makes the box look pressed in.

Why use more than one layer?

Stacking a large soft shadow with a small sharper one looks more natural than a single shadow. You can use up to 5 layers, and the code separates them with commas.

Does the code include the box corners and colors?

No. The background, box color and corner settings are only for the preview. The code contains the box-shadow line only, so add your own border-radius if you need rounded corners.

What is the Neumorphic preset?

Neumorphism is a style where an element looks softly raised from a background of the same color, using one light shadow and one dark shadow. It can have low contrast, so use it with care for important buttons.
