How to use the CSS Gradient Generator

  1. Start with one of the ready-made gradients, like Sunset or Ocean, or press Random.
  2. Choose the Type: linear, radial or conic. The controls change to match the type.
  3. Change each color with the color square, and set where it sits from 0% to 100%. Press Add color to use more colors.
  4. Press Reverse to flip the order of the colors.
  5. Press Copy CSS and paste the line into your style sheet.

About this tool

A CSS gradient is a smooth change from one color to another, drawn by the browser without an image. It loads fast and looks sharp on every screen size. This tool builds the code for you with a live preview, in your browser.

Frequently asked questions

What is the difference between linear, radial and conic?

A linear gradient changes color along a straight line. A radial gradient spreads outward from a center point. A conic gradient turns around a center point, like a color wheel or a pie chart.

What does the angle mean?

For a linear gradient, 0 degrees goes upward, 90 degrees goes to the right, and 180 degrees goes downward. For a conic gradient, the angle is where the turn starts.

How many colors can I use?

From 2 to 8. The percentage of each color tells where that color is at its full strength. The code lists the colors in order of their percentage, as CSS expects.

Does it support transparency?

Not yet. The color squares choose solid colors only.

Which browsers support conic gradients?

All current versions of Chrome, Edge, Firefox and Safari support linear, radial and conic gradients.
