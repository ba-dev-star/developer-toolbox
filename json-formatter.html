JSON Formatter and Validator

Paste your JSON, then format it, minify it, or check it for errors. Everything runs in your browser.

How to use the JSON Formatter

  1. Paste your JSON into the Input box, or press Load example.
  2. Press Format to make it easy to read, or Minify to remove all extra spaces.
  3. Choose the indent you prefer: 2 spaces, 4 spaces or a tab.
  4. Press Validate if you only want to check the JSON. When something is wrong, the message tells you where.
  5. Press Copy result to copy the output.

About this tool

JSON (JavaScript Object Notation) is the most common format for sending data between apps and servers. This tool formats, minifies and validates JSON in your browser, so your data is never uploaded.

Frequently asked questions

Why does my JSON show an error?

The tool follows the strict JSON standard. The most common mistakes are a comma after the last item, keys without double quotes, single quotes instead of double quotes, and comments. None of these are allowed in JSON.

Does formatting change my data?

The values stay the same, with two small effects of the way JavaScript reads JSON. Whole numbers larger than 9,007,199,254,740,991 can lose precision, and keys that are whole numbers (like "1" or "2") move to the top of their object. If a key appears twice, only the last one is kept.

What is the difference between Format and Minify?

Format adds line breaks and indentation so the JSON is easy to read. Minify removes them to make the JSON as small as possible, which is useful when sending it over a network.

Is my JSON uploaded anywhere?

No. Everything runs in your browser, on your device.
