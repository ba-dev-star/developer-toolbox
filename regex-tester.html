How to use the Regex Tester

  1. Type your regular expression in the Pattern box, without the slashes. You can press Load example to see how it works.
  2. Tick the flags you need, such as g to find all matches or i to ignore case.
  3. Type or paste your text in Test string. The matches are highlighted as you type.
  4. Look at the Matches list to see each match, its position, and the content of every group.
  5. To test a replacement, type it in Replace with. The result appears in Replace result.

About this tool

A regular expression (regex) is a pattern used to find, check or change text. Developers use them to validate emails, extract data from logs, and search and replace text in code. This tester uses the JavaScript regex engine of your browser, and your text never leaves your device.

Frequently asked questions

Which regex flavor does it use?

JavaScript (ECMAScript). Most basics are the same in other languages, but some features and syntax differ. For example, named groups are written (?<name>...) in JavaScript and (?P<name>...) in Python.

What do the flags g, i, m, s and u do?

g finds all matches instead of only the first one. i ignores uppercase and lowercase. m makes ^ and $ match at the start and end of every line. s lets the dot match new lines. u turns on full Unicode support, which you need for patterns like \p{L}.

How do I use groups in the replacement?

Use $1, $2 and so on for numbered groups, $<name> for named groups, and $& for the whole match. For example, replacing (\d+)-(\d+) with $2-$1 swaps the two numbers.

Why do I see only one match?

The g flag is probably off. Without it, a regular expression stops after the first match.

Can a pattern freeze the page?

Yes. Some patterns with nested repeats, like (a+)+, can take a very long time on some text. This is a known problem called catastrophic backtracking. If the page freezes, simplify the pattern or close the tab. The tool also shows at most 1000 matches.
