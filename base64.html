Base64 Encoder and Decoder

Convert text to Base64, or decode Base64 back to text. Works with any language, including Arabic.

How to use the Base64 Encoder and Decoder

  1. Type or paste your text into the Input box.
  2. Press Encode to turn text into Base64, or Decode to turn Base64 back into text.
  3. Press Swap to move the result into the input box, so you can convert it again.
  4. Press Copy result to copy the output.

About this tool

Base64 is a way to write data using only letters, numbers and a few symbols. It is often used to put data inside JSON, URLs, emails and tokens. This tool works with any language, including Arabic, and runs in your browser.

Frequently asked questions

Is Base64 a form of encryption?

No. Anyone can decode Base64, so it does not protect anything. Use it to transport data, never to hide secrets.

Does it work with Arabic and emoji?

Yes. Text is converted as UTF-8, so Arabic letters and emoji encode and decode correctly.

Which Base64 formats can it decode?

Standard Base64 and the URL-safe version that uses - and _ are both accepted. Missing = signs at the end are also fine.

Why does decoding fail?

Usually the text has characters that are not part of Base64, or it is incomplete. The result can also fail when the Base64 holds a file or an image instead of text, because this tool decodes text only.

Can I convert files or images?

Not yet. This tool converts text only.
