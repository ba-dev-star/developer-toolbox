HTML Entities Encoder and Decoder

Convert special characters to HTML entities so they display safely in a web page, or turn entities like &lt; back into normal text.

Common entities

&amp; &
&lt; <
&gt; >
&quot; "
&#39; '
&nbsp; non-breaking space
&copy; ©
&euro; €
&mdash; —
&hellip; …
Decoding understands all numeric entities (like &#233; and &#xE9;) and the most common named ones. Rare named entities are left unchanged. Entities must end with a semicolon.
