URL Encoder and Decoder

Encode text so it is safe inside a URL, or decode percent-encoded text like %20 back to normal. Works with any language, including Arabic.

How to use the URL Encoder and Decoder

  1. Type or paste your text or URL into the Input box.
  2. Choose the mode: Component for a single value, or Full URL for a whole address.
  3. Press Encode to make the text safe for a URL, or Decode to turn it back into normal text.
  4. If you are decoding a query string from a web form, tick Treat + as space when decoding.
  5. Press Copy result to copy the output, or Swap to use it as the new input.

About this tool

A URL can only contain a limited set of characters. Spaces, Arabic letters, emoji and symbols like & and = must be written as a percent sign followed by two hex digits, which is called URL encoding or percent encoding. This tool encodes and decodes text in your browser, so nothing is uploaded.

Frequently asked questions

What is the difference between Component and Full URL mode?

Component mode also encodes characters such as / ? & = and :, so use it for one value, like a search word or a query parameter. Full URL mode keeps those characters as they are, so use it for a complete web address.

Why do spaces become %20?

A space is not allowed inside a URL, so it is written as %20. The number 20 is the hex code of the space character.

When should I tick "Treat + as space"?

In data sent by web forms, a + sign often means a space, while %20 always means a space. Tick the option when you decode a query string that comes from a form. Leave it off when a real + sign is part of your data.

Does it work with Arabic?

Yes. Text is converted as UTF-8, so Arabic letters and emoji are encoded and decoded correctly. For example, the Arabic word مرحبا becomes %D9%85%D8%B1%D8%AD%D8%A8%D8%A7.

Why does decoding show an error?

Usually the text contains a % sign that is not followed by two hex digits, such as "100%", or the encoded bytes are not valid text. Fix or remove that part and try again.
