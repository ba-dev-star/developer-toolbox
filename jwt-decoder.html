About this tool

      
A JWT (JSON Web Token) is a compact token that apps use to prove who a user is. It has three parts separated by dots: the header, the payload and the signature. The header and the payload are JSON text written in Base64URL, so anyone can read them. This tool decodes them in your browser and does not send your token anywhere.


      
Frequently asked questions

      

        Does this tool check the signature?
        
No. It only decodes the token, so it cannot tell you if the token is genuine. The signature must be verified on your server with the secret or public key. Never trust a token just because it decodes.

      

      

        Is it safe to paste my token here?
        
The decoding happens in your browser and nothing is uploaded. Still, a live token can give access to an account, so avoid pasting production tokens into any website you do not fully trust. For testing, use expired or test tokens.

      

      

        What do exp, iat and nbf mean?
        
exp is the time the token expires, iat is the time it was issued, and nbf is the time before which it is not valid. They are Unix timestamps in seconds, and the tool shows them as readable dates.

      

      

        Do I need to remove the word Bearer?
        
No. If you paste the whole Authorization header value, the word Bearer at the start is removed automatically.

      

      

        Why does it say a JWT has 3 parts?
        
A signed JWT always has the form header.payload.signature, with two dots. This message means the text is missing a part or was cut when it was copied. Encrypted tokens (JWE) have five parts and are not supported.
