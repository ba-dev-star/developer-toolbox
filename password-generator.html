Password Generator

Create strong random passwords. They are generated in your browser and never sent anywhere.

How to use the Password Generator

  1. Move the Length slider. A longer password is a stronger password.
  2. Tick the character types you want: uppercase, lowercase, numbers and symbols.
  3. A new password appears every time you change an option. Press Generate new password to get another one.
  4. Press Copy and paste the password into your password manager or sign up form.

About this tool

This tool creates random passwords using the secure random number generator built into your browser. The passwords are made on your device and are never sent or saved anywhere.

Frequently asked questions

Is this password generator safe?

Yes. It uses the secure random generator of your browser, not a simple random function, and nothing leaves your device. As with any password, store it in a password manager.

How long should my password be?

For most accounts, 16 characters or more with a mix of character types is a strong choice. Use a different password for every account.

What does the strength in bits mean?

Bits are a rough measure of how hard a password is to guess. More bits is stronger. About 60 bits is strong and 80 bits or more is very strong.

Does it always include every type I choose?

Yes. If you tick uppercase letters, numbers and symbols, the password always contains at least one of each.

Does it save my passwords?

No. When you close or refresh the page, the password is gone.
